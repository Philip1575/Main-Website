Things I built

I design, test, and maintain these myself. Most of the code was written with AI assistance.

GUASFCU finance team, live since November 2026

Reconciliation website

A password-protected internal site that automates seven of the credit union’s daily and monthly reconciliations, including the Federal Reserve account. Each one takes the month’s exports and last month’s workbook and produces the finished workbook plus the entries to post. Files are processed only in the browser. Every rec runs a check that ties the output back to source balances before anything is downloaded, and saved test runs catch accidental changes. I designed it and handled the improvements and testing, with a colleague as co-builder and tester. It saves the team an estimated 25 hours a month.

Internal tool, so there’s no public link.

Personal system, runs every morning

AI daily planner

Between classes, recruiting, work, and training, I needed one place that told me what mattered today. Every morning at 8, an AI agent reads my notes, email, calendar, and course site without changing any of them. It writes the day’s plan: the top three actions, today’s schedule, deadlines this week, and who I’m waiting on. It updates a checklist page I use from my phone and sends me a notification. When I check something off or leave a note like “moved to Thursday,” the next morning’s plan picks it up. I set the rules it works by, including that it never sends email or changes my calendar.

Built with Claude Code. Private, so there’s no public link.

Personal project, still evolving

Garmin training data workflow

A local Python tool that pulls my workouts, laps, sleep, and HRV into organized files. It backfills any date range and runs a scheduled daily sync that catches up on missed days. I wrote the requirements and decided how the data should be collected and organized. It taught me to plan for missing values and keep the documentation clear.

Not affiliated with Garmin. View the source on GitHub

Runs every day at noon

Self-updating training page

The season strip, totals, and IRONMAN distances on this site update themselves. A scheduled script reads the Garmin tool’s local data (January and February come from a one-time Strava export), keeps only dates, sports, distances, times, and sleep scores, and publishes to GitHub when something changed. It refuses any update that looks like lost data or includes a field outside that list, and leaves the site unchanged.
