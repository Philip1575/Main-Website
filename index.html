Featured project

Garmin training data workflow A local Python workflow built with AI assistance to collect and organize activity and recovery data. Personal project · Evolving Read the projectClose project details

View source and installation instructions on GitHub

The problem

I wanted a repeatable way to bring workout details and available recovery metrics into organized local files for personal training analysis.

My role

I used Python and Codex to build and refine the workflow, with AI assistance throughout development. I shaped the requirements and worked through how the data should be collected, organized, and used.

The workflow

  • Import historical data for a selected date range.
  • Run scheduled daily updates, with missed-run catch-up when the computer is available.
  • Keep workout details, laps, and splits alongside available sleep, HRV, and other metrics.
  • Read organized local files with compatible AI tools, or upload selected files manually.

What I’m learning

The project has made data availability, missing values, repeatable updates, and clear documentation central to how I think about a useful workflow.

Current status

This is an evolving personal project. A Windows starter package for friends has undergone local checks; testing on a fresh computer is still pending. The tool collects and organizes data. It does not independently prescribe training and is not endorsed by Garmin.

The scheduled task downloads data locally. Any use with an AI tool is a separate, intentional step.
